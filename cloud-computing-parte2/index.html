Cloud Computing (Parte2)

23 de enero de 2012 · 1 minuto de lectura

Tras una primera introduccion que hice sobre Cloud Computing ,voy a seguir dando algunos puntos claves de esta tecnología.

El estilo de computación Cloud Computing, tiende a parecerse al estilo tradicional de los MainFrame, donde un cliente se conectaba desde su terminal a el megaservidor. Aquí una imagen de la evolución arquitectónica que han tenido los sistemas en las ultimas décadas. Un Cloud Computing se puede desplegar bajo una infraestructura:

- Cloud Privada: propiedad de una empresa. Son redes construidas y ejecutadas por un único cliente, teniendo control total de datos, seguridad, calidad del servicio. Puede ser construido por tu propia compañía o contratando servicios de proovedores de cloud. - Cloud Publica: vendida al publico a gran escala. (Ejemplo amazon web services). La Cloud publica corre en lugares externos, y las aplicaciones son de diferentes clientes haciendo un mix entre servidores, almacenamiento, sistemas y redes. - Cloud Hibrida: composicion de dos o mas cloud. Introduce la complejidad de determinar como distribuir las aplicaciones entre ambos cloud.

Cuando se dice que una empresa ha desarrollado una aplicación sobre el Cloud Computing, esta frase puede tener varias interpretaciones. Existen tres tipos en las que pueda estar desarrollado un servicio.

- Software as a Servicie: Ha desarrollado un servicio o aplicación web sobre la nube. Nos conectaremos con nuestro navegador para poder acceder a esa herramienta. -  Attached Services: Tiene recursos o funciones extra desplegadas en el Cloud, pero sigue manteniendo la filosofía de que el cliente debe tener instalada una parte de la aplicación. - Cloud Platform: La aplicacion esta desarrollada bajo el cloud, que tiene previamente instalada una plataforma en particular.
