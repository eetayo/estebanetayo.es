Cloud Computing (Parte1)

27 de diciembre de 2011 · 2 minutos de lectura

Dicen que el año 2012 sera el año del Cloud Computing . Mucho se esta oyendo este termino pero también mucho humo se esta vendiendo. Parece que es un nuevo mundo donde todo es posible, parece un ente diferente al internet de hoy en dia, parece que todos los problemas seran resueltos... desde luego que es una tecnología increíble pero no es mas que una evolucion natural de la manera que los servidores han de funcionar.

En resumen, el Cloud Computing es el Santo Grial para los administradores de sistemas pero para el usuario final, el que usa Internet, para ese, no le influirá en nada. Antes del Cloud Computing todo estaba evolucionado hacia un almacenamiento de datos en la red (correo electronio, repositorios, etc..) y con él todo se esta acelerando (Calendario, Herramientas Ofimaticas, etc..).

La característica principal del Cloud Computing es la Escalabilidad , cuando alguien desarrolla un sistema puede que inicialmente pueda ser utilizado por un maximo de 5 personas paralelamente, pero tras una fuerte inversion este sistema empiece a ser utilizado por gran cantidad de personas en el mundo. Este problema lo resuelve el Cloud Computing.

Dentro del Cloud Computing tenemos gran cantidad de proovedores donde elegir, cada uno con unas caracteristicas diferentes y con unos precios diferentes. A modo global podemos dividirlos en diferentes tipos segun el control que nos permitan realizar, ellos son: SaaS(Software as a Service): Solo nos permite el uso de la aplicación del proveedor sobre la red. No podemos desplegar servicios propios. PaaS(Platform as a Service): Despliega aplicaciones creadas por clientes a la nube. El proveedor nos posibilitara el método bajo el cual hemos de desarrollar nuestras aplicaciones para poder se desplegadas sobre dicho sistema. IaaS(Infrastructure as a Service) : Alquilar procesamiento, almacenamiento, capacidad de red y otros recursos computacionales. El cliente tiene acceso a poder realizar una administración completa de su infraestructura sobre la red.

Como se puede apreciar, contra mas bajo sea el nivel, mas control tenemos sobre los recursos del sistema.
